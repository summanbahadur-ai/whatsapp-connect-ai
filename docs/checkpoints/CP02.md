## Implemented

- V1 Java identity, credentials, hashed verification tokens and JDBC session tables.
- V2 reviewed static domain schema: 37 public business tables, enums, constraints,
  indexes, functions, triggers and row-level security. No source runtime dependency.
- V3 identity provisioning/profile synchronization, least-privilege grants,
  protected membership columns and explicitly allowed account functions.
- Separate migration/owner, auth, app and worker JDBC pools; explicit database
  profile. Default foundation profile remains database-free.
- Account transaction wrapper sets transaction-local identity on the same
  connection, reloads membership/role and rejects nested identity scopes.
- Database-name/credential-option guard prevents accidental old-database targets.
- Password-free role/database bootstrap SQL; ignored private configuration generator.
- Master database/schema.sql, deterministic sync helper and synchronization test.
- Repeatable local-only PostgreSQL test cluster, independent of installed server5432.

Normal local setup is documented in ../../database/README.md. Existing source SQL
under docs/reference remains documentation only and must not be run directly.
